# Docs

| Area | What lives there |
|---|---|
| [`guides/`](guides/) | How to install and run an integration (`<host>.md`) |
| [`specs/`](specs/) | Feature specs (`SPEC-<feature>.md`) |
| `adrs/` | Architecture decision records (`ADR-NNN-<topic>.md`) — none yet |

Planning scratch — step-by-step implementation checklists, session notes —
is not documentation. Keep it out of the repo; git history already records
how something was built.
